**🍽️ Swiggy Sales Analysis Dashboard – Excel Project**

**📌 Project Overview**

This project focuses on analyzing Swiggy restaurant and sales data using Microsoft Excel. The objective is to organize the data, explore sales performance, identify popular dishes and restaurants, and present meaningful insights through PivotTables and an interactive dashboard.

Dataset used:

This project focuses on analyzing Swiggy restaurant and sales data using Microsoft Excel. The objective is to organize the data, explore sales performance, identify popular dishes and restaurants, and present meaningful insights through PivotTables and an interactive dashboard.

**🎯 Project Objectives**

Analyze sales and revenue performance.

Identify top-performing restaurants and popular dishes.

Explore key business metrics using PivotTables.

Present data-driven insights through an Excel dashboard.

Improve data analysis and visualization skills using Excel.


**📊 Interactive Dashboard**

The Swiggy Sales Analysis Dashboard provides a visual overview of restaurant performance, sales trends, popular dishes, and customer ordering patterns. It brings together key analysis from different worksheets into one place, making it easier to understand business performance and identify useful insights.




**Dashboard view:**
<a href ="https://github.com/Aniketyadav004/Excel-2/blob/main/swiggy%20dashboard.png"> Dashboard View</a>


**Dashboard Visualizations**

Top-Selling Dishes: Identifies dishes generating high sales.

Restaurant Performance: Compares restaurants based on their sales and revenue.

Restaurant Ratings: Helps explore restaurant ratings and customer preferences.

Monthly Sales Trends: Visualizes sales patterns across different months.

Location-Wise Sales: Compares sales performance across different locations.

Category-Wise Analysis: Examines the contribution of food categories, such as desserts, main courses, beverages, and burgers.

Product-Level Insights: Highlights product-level information to support sales analysis.




**📂 Project Structure**

The Excel workbook contains the following sheets:

Swiggy Data: Main dataset used for analysis.

Pivot Table: Summarized data for exploring trends and performance.

Dishes: Analysis of dish-level performance.

Restaurant: Restaurant-level analysis.

Sales: Sales-related summaries and metrics.

Dashboard: Visual representation of key business information.
